# Workshop profile (persistent)

## Where it lives

`~/.mechanical-designer/workshops/<workshop-name>.yaml`, one file per workshop (the user's own, a contracted shop, a client's). Use `assets/templates/workshop-profile.yaml` as the starting point. Projects record which profile they used.

The skill files are generic and shared; the profile belongs to the user. Never write user data into the skill folder.

## First time (no profile yet)

Do a short overview, not an inventory form: "Which machines and tools do you have? A quick list is fine — for example: lathe, drill press, MIG welder, angle grinder, 3D printer." Plus: "What do you (or whoever builds it) master, and what not?" and "What do you measure with?" Save what you learn; fill details later.

## Progressive detail

Ask for specifics only when a part needs them, then save them:
- part needs aluminium welding → "Does your TIG welder have AC, and does the welder have aluminium practice?"
- part is a 400 mm shaft → "What is your lathe's distance between centres and swing?"
- sheet part 3 mm × 1.2 m → "Bending length and max thickness of your brake?"

Each answer goes into the profile with the date. Never ask the same thing twice.

## Each new project

Load the profile, summarize it in one line, and ask only: "Any new equipment or changes since last time?"

## What to capture per machine

Type and model, working envelope (travel, swing, bed size, bending length), capacity (max thickness, diameter, amperage), accuracy, accessories (dividing head, rotary table, tailstock, steady rest), materials it handles, and condition notes. For people: processes they master, ones they don't, certifications.
