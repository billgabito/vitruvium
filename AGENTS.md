# AGENTS.md

This repository contains **DaVinci Mechanical Designer**, an agent skill for mechanical design based on mechanical simplicity. It follows the open Agent Skills format (a `SKILL.md` with YAML frontmatter plus `references/` and `assets/`), so any AI agent that reads files can use it.

When the user asks to design, redesign, audit or fabricate a mechanical part, mechanism or assembly, read and follow:

`skills/davinci-mechanical-designer/SKILL.md`

Load the files in `skills/davinci-mechanical-designer/references/` only when the step you are on needs them.
